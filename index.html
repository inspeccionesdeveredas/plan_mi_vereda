      Todavía no cargaste registros. Cuando termines, descargá el Excel con tus registros nuevos y mandáselo por WhatsApp o mail a quien te compartió este archivo. Lo que cargues queda guardado en este navegador; si agregás más después, volvé a descargar y mandá el archivo nuevo.

        Los cambios se guardan solos en este navegador. Para conservarlos en otra compu o compartirlos, descargá el dashboard actualizado: es un archivo HTML nuevo con los datos incluidos.

        Los cambios se guardan en línea al instante. Para trabajar sin internet, descargá una copia del dashboard con los datos de este momento.
